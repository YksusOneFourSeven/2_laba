# Практическая работа 17 — пакет DOC-17

Комплект документации для принятия решения по учебному кандидату `1.5.0-rc1`.

## Состав сдачи

1. [`checkpoint_1.md`](checkpoint_1.md) — промежуточный результат первой пары.
2. [`release_passport.md`](release_passport.md) — паспорт выпуска.
3. [`traceability.md`](traceability.md) — матрица трассировки пяти требований.
4. [`test_protocol.md`](test_protocol.md) — протокол известных результатов и запланированных проверок.
5. [`release_runbook.md`](release_runbook.md) — регламент окна, остановки и возврата.
6. [`documentation_changes.md`](documentation_changes.md) — замечания и исправленный фрагмент руководства.
7. [`release_decision.md`](release_decision.md) — итоговое решение STOP и условия пересмотра.
8. [`peer_review.md`](peer_review.md) — самостоятельная сквозная проверка.

Исходные данные находятся в каталоге [`Data`](Data). Снимки макета Figma сохранены в [`assets`](assets) как приложения; они не подменяют результаты тестов. Все результаты учебные; фиктивные подписи, даты испытаний и внешние ссылки не добавлялись.
